# Independent v0.4 trials

Pódio: table-tennis scoring. Véspera: guest seating. Revela: photo-film processing. Synthetic content and local operations only.

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory dist
```

Open http://127.0.0.1:8768/ in a browser. No build, dependency, account or API key. Progress belongs to this browser/origin.

`inputs/` preserves functional briefs, protocol, neutral study capture exchanges, preselection study sources and frozen skill. The snapshot's SKILL.md is named `entrypoint.md` to avoid duplicate skill discovery; bytes/hashes are unchanged.

`dist/<case>/` contains each closed submission, unmodified by the evaluator. Creators could inspect neutral captures and revise their own work before closing; see DESIGN.md and QA.md for those changes. `screenshots/*-ui-*` are creator-requested preflight captures, including earlier states; `*-desktop.jpg` and `*-mobile*.jpg` are final evaluator captures. Studies are full-page images. `SHA256SUMS.json` verifies final submissions.

Read [QA](QA.md) for tested paths and limits. Broader identity diversity was observed, with residual typography/wordmark overlap. These new briefs and renderer support do not constitute a controlled comparison against v0.3. The previous hosted Sites gallery was not updated; this folder is a runnable local artifact.
