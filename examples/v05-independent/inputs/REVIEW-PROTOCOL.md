# Evaluator protocol — not supplied to creators

Freeze skill before dispatch. Each creator gets its own functional brief and frozen instructions. Provide requested renders/dimensions/actions without preference or critique. Preserve preselection study files and capture exchanges. Freeze final sources after creator-led checks; no post-close correction. New briefs cannot establish a causal v0.4/v0.5 comparison.

Inspect typography, name construction, full palette and composition separately, including second working state and phone. Record recurrence honestly; do not score novelty by unique font count. Check whether system font resources render as intended and record portability limits. Compare with v0.4 only as unmatched observations.

Browser targets: 1440×900, 390×844, 320×740; measure actual viewport and document width. Capture full-page studies at 1440×1000 and phone. Exercise main tasks and recovery:

- Revez: overdue status; unavailable/maintenance restrictions; name/date validation; loan review/cancel/confirm; return confirmation; undo; history and reload; search/filter recovery.
- Vereda: supplied branching text; back and alternate path; route recap; final restart cancel/confirm; font-size and route persistence.
- Minuto: timing format/range/duplicates; immutable first timestamp/deletion; add/rename/update; delete cancel/confirm/undo; interval calculations; reload; actual exported file contents.

Record creator-requested preflight separately from final evaluator evidence. No participants, blinded panel, matched baseline, full keyboard or screen-reader audit, native app testing, or guarantee of uniqueness.
