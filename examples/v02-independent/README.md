# Independent Authentic Design v0.2 trials

Three fresh implementation tasks using a frozen v0.2.0 skill. No extra art direction, prior outputs, or parent corrections were given. Submitted prototype files are kept unchanged in dist/archive, dist/kitchen, and dist/learning. The gallery itself is evaluator-authored and is not one of the three trials.

Serve locally from this folder:

```sh
python3 -m http.server 8766 --directory dist
```

Open http://localhost:8766/. The projects use local relative assets and browser-local state, without a build step or real transactions. Protocol, exact requests and input hashes are in inputs/; screenshots and the evaluation report record the observed output and any defects. This is one implementation per brief, not a controlled benchmark or participant study.
